AIcademiya 本机运行说明

前端已迁移到 Vue 3，后端沿用 FastAPI。应用版本和数据库版本保持原值。当前开发分支为 vue-java-cys。

启动和停止

在 app 目录双击 start.cmd，或通过 PowerShell 7 执行：

pwsh.exe -NoProfile -File .\start.ps1

默认地址：http://127.0.0.1:18773/。窗口持续运行时提供服务，按 Ctrl+C 停止该窗口启动的服务。已有同端口服务时会返回地址，不会结束其他进程。

首次配置环境时运行 pwsh.exe -NoProfile -File .\setup.ps1。安装脚本准备项目 Python 环境、安装依赖并构建前端；没有配置文件时创建默认文件，不覆盖已有文件。

只编辑 config.json

配置文件位于 app/config.json。修改后重启本机服务。所有相对路径均相对于这个文件的所在目录解析。启动脚本以该文件为准，不再从旧 local-settings 文件或数据库读取部署配置；旧设置记录仍保留。

节点配置项与作用
serverhost、port、open_browser：后端地址、端口及自动打开网页。
frontendhost、port：Vite 开发服务器地址和端口，静态部署无需另外启动 Vite。
storagedata_dir、catalog_path、upload_dir、frontend_dir：数据库目录、首次初始化课程种子、上传目录、构建产物目录。种子只在数据库初始化时导入。
authdemo_enabled、registration_enabled、cookie_secure、allowed_origins、allowed_hosts：演示登录、学生注册和部署访问策略。当前演示仅绑定本机回环地址。
aiprovider、mode、base_url、model、api_key、use_environment_proxy；另有 timeout_seconds、temperature、enable_thinking、thinking_budget。默认使用硅基流动的 Qwen3.8-27B，直连，读取超时 120 秒，温度 0.3，关闭思考模式；开启思考后默认预算 4096 token。密钥只在本机文件填写。
searchenabled、api_key：原有搜索功能，默认关闭。
documentsworker_command（参数数组）、formats、worker_timeout_seconds：可选完整文档工作器。当前命令数组为空，不启动外部处理器。

配置文件不进入 Git，也不会作为前端资源发送。未知配置键、类型错误和非法端口会在启动时明确报错。

本机演示与硅基流动接入

登录页的 Teacher / Student / Admin 按钮使用合成账号。课程和材料位于 local-demo，数据保存在 data-local；原有课程资料和数据库没有迁入或清空。演示登录与 AI 模拟回复是独立设置：ai.mode=openai 时使用真实接口。

硅基流动配置为 provider=siliconflow、mode=openai、base_url=https://api.siliconflow.cn/v1、model=Qwen/Qwen3.8-27B。在 ai.api_key 填写密钥后重启服务，后台通过 Bearer 认证调用 POST /v1/chat/completions。读取模型列表的连接检查不生成内容；管理员可通过后端接口 POST /api/teacher/settings/test 发起一次真实生成测试。缺少密钥时显示未配置，不发送请求；认证、限流和响应不完整均明确报错，不以模拟回复替代。思考内容不会作为最终教学回答展示。

参数范围：超时 1–600 秒，温度 0–2，思考预算 128–32768 token。thinking_budget 只在开启思考时发送；各教学任务继续使用原有的输出长度上限。工具调用、JSON 输出和图像消息复用统一适配器；本地推理服务专用的缓存参数不发送到硅基流动。请求默认不自动重试，避免重复生成。

官方依据（2026-10-16 查阅）：Chat Completions 文档、模型列表接口、模型目录。协议测试使用合成响应；真实生成检查仅证明当次连通，不代表任意课程的教学质量。

2026-10-16 验证记录：127 项针对性后端测试通过，另有 1 条既有 Starlette 弃用提示；真实模型列表包含 Qwen/Qwen3.8-27B，通过本机后端发起的 32 token 上限生成检查成功，耗时约 1.27 秒。本轮未进行完整课程的教学质量验收。

开发和检查

# app 目录：检查环境，不启动服务
pwsh.exe -NoProfile -File .\start.ps1 -Check

# frontend 目录：开发、针对性测试及构建
npm run dev
npm test
npm run build

浏览器访问后端地址时使用 frontend/dist；源码更新后运行构建，再刷新网页。详情见 frontend/README.md。
