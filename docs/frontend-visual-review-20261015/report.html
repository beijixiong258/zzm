F03 · 优先调整响应式布局 · 已量测

学习区出现多层滚动，输入区不能稳定留在视野内

观察：1366×768 下页面总高 882 像素，源码为学习区设置 min-height:820px。390×844 下，无错误提示的示例对话页面总高 1312 像素，输入框顶部在页面纵向 1056 像素。页面、对话内容及答案面板分别滚动；手机截图可同时看到外层与内层滚动条。

建议：以可用窗口高度分配学习区，压缩课次头部；对话采用一个主要滚动区，输入框固定于学习区底部。手机端将材料和已保存答案做独立全屏面板，保留清晰的返回会话入口。

验收：1366×768 与390×844下，输入区无需滚动整页寻找；答案面板打开和关闭后恢复原会话阅读位置。手机软键盘需后续真机验证。

F06 · 第二批调整状态表达 · 设计判断

草稿、发布版本与课堂开放状态缺少清楚的视觉关系

观察：课次卡片可同时显示 Draft 与 Open；编辑页并列 Editing draft、Open、Publish & version history。首页称 Version history，侧栏称 Publish & versions，编辑页又称 Publish & version history。版本页同时承担发布与历史比较。

影响：三个独立概念本身合理，但新教师需要阅读多处说明才能判断学生当前看见什么、保存后何时生效，以及下一步应操作哪里。

建议：统一入口名称；用“正在编辑的草稿 / 学生当前版本 / 课堂开放状态”三项清楚呈现。保存后提供发布检查入口，检查页集中展示将对学生生效的变化。

验收：教师无需解释技术术语即可回答：学生正在使用哪个版本、当前修改是否已对学生生效、是否允许进入课堂。

F10 · 后续统一视觉规范 · 设计判断

页面标题、内容容器与设置导航缺少统一尺度

观察：首页和教学工作台使用大衬线一级标题，Course versions 与 Course Students 页面以较小二级标题开始；Settings 与内部 Account/Feedback 又各自出现一级标题。平板反馈页仍保留一列局部导航，使正文进一步收窄。

建议：制定统一的页面头部、表单间距、主次按钮和字号规则。每个页面保留清晰的主标题，设置分区用次级标题；平板将短局部导航改为横向标签。现有森林绿、浅底色和品牌图形可继续使用。

验收：同类页面使用一致的标题层级、宽度与间距；关键标签和操作清楚，辅助说明不抢占第一阅读层。
