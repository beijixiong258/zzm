弹窗与导航取消未保存内容使用站内提示。手机编辑窗固定底部操作区，短确认框居中紧凑显示，实测约 272 px 高。抽屉提供明确的关闭按钮，退出登录后重置。

配置地址、端口、存储、认证、模型、搜索、文档工作器参数集中在 config.json；设置页只显示部署状态。Qwen 接口、模型名和密钥仍待填写。
